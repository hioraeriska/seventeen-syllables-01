Entry for the [Seventeen Syllables of Debugging](https://make.fun/competitions/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun: one haiku about debugging, three lines in the 5-7-5 syllable shape.

`main.ts` writes the haiku to `/output/entry.txt`:

```text
Breakpoint never fires
the log insists all is well
so the bug is me
```

66 characters, 5-7-5 syllables. The breakpoint never fires, the log insists
everything is fine — and the last line turns it around: the bug is the human.
